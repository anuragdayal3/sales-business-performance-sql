# Sales & Business Performance Analysis using SQL

## Project Overview

This project analyzes sales data using PostgreSQL to understand customer behavior, product performance, employee performance and overall revenue.

## Tools Used

- PostgreSQL
- pgAdmin 4
- SQL

## Database Tables

- Customers
- Products
- Employees
- Departments
- Orders

## Business Questions

The project answers 20 business questions covering:

- Sales and revenue analysis
- Customer analysis
- Employee performance
- Department performance
- Product performance
- Revenue contribution
- Advanced SQL analysis

## SQL Concepts Used/skills

- SELECT
- WHERE
- GROUP BY
- HAVING
- JOINs
- Subqueries
- CTEs
- Aggregate Functions
- Window Functions
- DENSE_RANK()
- CASE
- Running Totals
- Percentage Calculations

## Key Analysis

Some of the key questions include:

1. What is the total company revenue?
2. Who are the top customers?
3. Which products generate the most revenue?
4. Which employee generates the highest sales?
5. Which departments contribute the most revenue?
6. What products are top-selling in each category?
7. Which customers contribute to 80% of total revenue?

## Project Files

- `sales_analysis.sql` – Complete database creation, data insertion and analysis queries.
- `Screenshots/` – Selected query outputs from pgAdmin.
